# CSS Editor

Press **F1** → **Edit Character Select**, or the **Edit** button in the header, just left of the controls and gamepad icons.

The editor works on the roster portraits (`{id}_select`). While editing, the header and P1–P4 panels hide and the menu background stays. A gamepad hand uses Attack or Start to press the buttons, grab a portrait, mark one for removal, or choose an Add portrait.

- **Sort** — drag a portrait. Drop on a slot to insert, or just under the grid for a new row. A drop outside the grid snaps back.
- **Add** — pick a portrait that is not on the grid. The mouse wheel scrolls the tray.
- **Remove** — mark portraits, then **Confirm**. **Remove All** clears the grid and keeps Random.
- **Restore** — put back the original 1.4 roster (rows, position, and 42×42 icons).
- **Done** — leave edit mode and bring the header and panels back.

The grid stays on one screen. Icons shrink to fit the width of the chip area and the space above the P1–P4 panels.

Requires **Mod Menu**. Enable in **Vault → Manage Mods**.
