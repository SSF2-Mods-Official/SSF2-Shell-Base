# Stage Editor

Press **F1** → **Edit Stages**.

- **P1–P4** switch which Stage Select page you are editing.
- Drag icons to rearrange. Drop on a **gap** / empty slot to insert, or below the grid for a new row (max 6).
- Drop on **Unused** to bench. **Restore defaults** resets the lists.
- On Stage Select, the **SXP** button cycles pages that have stages.
- **F1 → Load extra stage** (Stage Select only) starts a match on a stage that is not on the grid.

Requires **Mod Menu**. Enable in **Vault → Manage Mods**.
